# KubeCrow Homebrew tap

```bash
brew install kubecrow/tap/kubecrow
```

Installs the latest [KubeCrow](https://kubecrow.com/) release (signed and notarized, Apple Silicon and Intel) from
[kubecrow/kubecrow](https://github.com/kubecrow/kubecrow/releases). KubeCrow updates itself; `brew upgrade --greedy`
also works. `brew uninstall --zap kubecrow` removes the app and its data.

The cask is updated by KubeCrow's release script on every release.
